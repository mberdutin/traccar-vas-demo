# Разработка на Mac и проверка в Kubernetes CI

Правила предлагаемого демо-процесса: разработка в feature-ветке на Mac,
проверка конкретного коммита в чистом Kubernetes sandbox, публикация
проверенного результата после выбранных условий выпуска.

Проверочное окружение совпадает с CI: образ по digest, платформа, Node,
браузеры, lockfile, тестовые данные, сервисы и одна команда проверки.
Такой прогон может считаться CI и не требует дублировать те же проверки.
Отчёт привязан к SHA, содержит команды, exit codes и артефакты. Новый код
или изменение значимой базы main требует повторной проверки.

В исходном package.json есть lint/build/start, готовой test-команды нет.
Для полного демо предстоит добавить тестовый набор, API/данные и preview.
Сборка frontend без backend ещё не доказывает правильность пользовательского сценария.

Файлы между Mac и Kubernetes передаются через Git. Совпадение истории чата
не означает наличие незакоммиченных файлов ноутбука в поде. Текущий Pi-Mac
имеет macOS sandbox и не переносится как есть на Linux; переход с сохранением
session_id — отдельная техническая проба до записи видео.
