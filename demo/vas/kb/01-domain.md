# Словарь VAS устройства координаты геозоны

Устройство device — объект наблюдения: машина, телефон или трекер.
Пользователь видит только доступные ему устройства. Группа group объединяет
устройства; фильтрация учитывает и родительские группы.

Позиция position — данные местоположения конкретного устройства. Запись
содержит координаты и несколько времён. В UI есть отдельные поля fixTime,
deviceTime и serverTime; их нельзя молча считать взаимозаменяемыми.

Геозона geofence — область, относительно которой можно показывать принадлежность
и события. В текущем фильтре карты используются geofenceIds позиции.
Назначение геозон пользователю и нахождение устройства в геозоне — разные задачи.

Статус online/offline/unknown не равен давности координаты. В строке устройства
используется device.lastUpdate для представления времени последнего обновления.
Для нового требования «недавно был на связи» надо уточнить, имеется ли в виду
сообщение устройства, время получения данных сервером или свежесть координаты.
